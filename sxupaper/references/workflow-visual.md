## 数据流向

### 场景 A 数据流

```
DOCX ──→ processor ──→ json + assets + md
                              │
                              ▼
                        lower-aigc
                              │
                              ▼
                        降AI版 md
                              │
                              ▼
                        processor ──→ DOCX
```

### 场景 B 数据流

```
DOCX ──→ processor ──→ md
                        │
                        ├──────────────────┐
                        ▼                  ▼
                  lower-aigc            (直接使用)
                        │                  │
                        ▼                  ▼
                   降AI版 md            原始 md
                        │                  │
                        └────────┬─────────┘
                                 ▼
                            sxuyear
                                 │
                                 ▼
                              DOCX
```

## 使用流程

1. **用户触发**：输入 `/sxupaper` 或提到"论文全流程"
2. **选择场景**：
   - 场景 A：修后论文（降 AI）流程
   - 场景 B：无修论文流程
3. **提供输入**：DOCX 文件路径
4. **配置选项**（场景 B）：是否需要降 AI
5. **自动执行**：sxupaper 自动协调各模块完成处理
6. **输出结果**：处理完成的 DOCX 文件

## 注意事项

- 场景 A 需要 processor 支持带锚点提取和回填功能
- 场景 B 的 correction 模块目前待开发
- 降 AI 处理会改变文本表达，但保持原文观点不变
- 最终输出的 DOCX 会符合山西财经大学论文规范
