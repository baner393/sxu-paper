# 山西财经大学学年论文格式转换工具

将 Markdown （注意，只支持markdown）论文自动转换为符合山西财经大学学年论文规范的 Word 文档（.docx）。
如需将docx转化为markdown，用本人仓库下的processor工具。

## 功能特性

- 自动按学校规范排版：封面、摘要、目录、正文、参考文献、致谢等
- 支持三线表、图注、脚注、交叉引用
- 奇偶页页眉页脚自动处理
- 封面信息自动填写（含专业代码）
- 批量处理多篇论文

## 使用方式

### 前置条件

- Windows 系统
- .NET SDK 8.0+
- Claude Code（安装此 skill）

### 目录结构

```
sxuyear/
├── .claude/skills/sxuyear/   # skill 文件
├── build/ThesisBuilder/      # C# 格式转换程序（Program.cs）
├── input/                    # 放入论文 Markdown 和图片
│   ├── 1/
│   │   ├── 学年论文.md
│   │   └── photo/            # 图片目录
│   └── 2/
├── template/                 # 格式规范和封面模板
└── output/                   # 生成的 Word 文档
```

### 使用步骤

1. 将论文 Markdown 文件放入 `input/` 目录（如 `input/1/学年论文.md`）
2. 将论文图片放入对应的 `input/{编号}/photo/` 目录
3. 在 Claude Code 中输入 `/sxuyear`
4. 按提示填写封面信息（专业代码、题目、姓名、学号等）
5. 生成的 Word 文档输出到 `output/` 目录

### 格式规范

- **纸张**：A4 纵向
- **页边距**：上 3cm、下 2.5cm、左 2.5cm、右 2cm
- **封面**：学校统一模板，页眉内容从学号自动提取年级
- **页码**：摘要/目录用罗马数字，正文用阿拉伯数字
- **正文**：宋体小四号，首行缩进 2 字符，1.25 倍行距
- **参考文献**：宋体小四号，方括号编号，悬挂缩进

### 多篇论文支持

在 `input/` 下创建多个子目录（1、2、3...），每个目录对应一篇论文：

```
input/
├── 1/
│   ├── 学年论文.md
│   └── photo/
│       ├── 图片1.png
│       └── 图片2.png
└── 2/
    ├── 学年论文.md
    └── photo/
```

## 常见问题

**Q: 目录无法自动更新？**
A: 在 Word 中右键目录 → 更新域

**Q: 三线表格式不对？**
A: 检查顶线、栏目线为粗线（1.5 磅），底线为粗线（1.5 磅），无竖线

**Q: 页眉页脚位置不对？**
A: 确认奇数页右对齐、偶数页左对齐

**Q: 封面下划线长度不对？**
A: 在空格处按空格键调整长度

## 范围

仅限山西财经大学可直接使用，其他学校的模板和格式需自行修改对应的配置后使用。
