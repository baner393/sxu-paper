# 学年论文格式转换

## 核心规则

1. **只使用 minimax-docx skill** 进行所有 Word 文档操作
2. 文档中的每一项要求都必须执行，不可省略
3. 执行顺序遵循装订顺序：封面 → 说明 → 学术承诺/使用授权 → 中文摘要与关键词 → 英文摘要与关键词 → 目录 → 正文 → 参考文献 → 附录 → 致谢 → 成绩评定表
4. 参照位于D:\360MoveData\Users\ban\Desktop\school_about\word_about\sxuyear\学年论文生成经验总结.md 的思路和注意事项


## 执行流程

### 步骤 0：发现输入文件

- 扫描 `input/` 目录，找到所有 `.md` 文件
- 如果用户指定了文件名（如 `/sxuyear 学年论文.md`），只处理该文件
- 如果未指定，处理 `input/` 下所有 `.md` 文件
- 多文章支持：每个 `.md` 文件视为一篇独立文章，按文件名排序后从 1 开始分配数字编号
- 每篇文章对应的图片从 `input/{数字编号}/photo/` 目录读取，按文件名排序插入文中
- 对于每个输入文件，执行以下全部步骤

### 步骤 1：读取输入

- 读取 `input/` 下目标 `.md` 论文文件，获取论文内容（标题、摘要、正文、参考文献等）
- 读取 `template/`下目标 `.md` 获取全部格式规范要求
- 如果是`template/`下目标为`山西财经大学学年论文格式.md`则不更新格式和规范要求
- 从论文内容中提取论文标题，用于后续文件命名

### 步骤 2：创建文档并设置页面基础

- 使用 minimax-docx 创建新文档
- 按格式规范设置纸张 A4、纵向、页边距（上3cm、下2.5cm、左2.5cm、右2cm）
- 设置文档网格为无网格

### 步骤 3：分节与页眉页脚

按格式规范设置分节符（下一页），实现不同区域的页眉页脚规则：
= **字号**：宋体/Times New Roman 小五号
- **封面、说明、学术承诺、使用授权说明**：无页眉、不显示页码
- **中文摘要、英文摘要、目录**：页眉、罗马数字页码。罗马数字页码Ⅰ、Ⅱ、Ⅲ（奇数右对齐、偶数左对齐）
- **正文至致谢**：页眉、阿拉伯数字页码，奇偶页不同位置（奇数右对齐、偶数左对齐）
- **页眉级数动态获取**：从学号前4位提取年级（如学号 `202406020153` → `2024级`），页眉内容为：`山西财经大学{级数}级本科生学年论文`
- 在 Program.cs 中定义：`static string GRADE => STUDENT_ID[..4];` 和 `static string HEADER_TEXT => $"山西财经大学{GRADE}级本科生学年论文";`

### 步骤 4：前置部分内容

- **封面**：空白页（学校统一模板，不自行设计），不加页眉、不加页码
- **说明**：空白页
- **学术承诺、使用授权说明**：空白页，确保首页在奇数页
- **中文摘要**：单独成页（奇数页），标题"摘 要"（中间空2格），宋体小二号加粗居中，段前段后1行。正文宋体小四号。关键词格式：黑体四号"关键词："+ 宋体小四号内容，分号分隔
- **英文摘要**：单独成页，标题"Abstract" Times New Roman 三号加粗居中，段前段后1行。Keywords 格式：Times New Roman 四号加粗左顶格 + 小四号内容，分号分隔
- **目录**：单独成页（奇数页），标题"目 录"（中间空2格），宋体小二号加粗居中。使用 Word 自动目录功能，只显示到二级标题。「导论」开始到「致谢」结束

### 步骤 5：正文排版

- **导论**：一级标题"1 导 论"，格式同一级标题
- **标题格式**：
  - 一级标题：黑体三号居中，段前段后1行，编号后空1格
  - 二级标题：宋体四号加粗左顶格，段前段后0行，1.25倍行距
  - 三级标题：宋体小四号加粗左顶格，段前段后0行，1.25倍行距
- **正文**：宋体小四号，首行缩进2字符，1.25倍行距

### 步骤 6：脚注（注释）

- 将正文中的 `[1]`、`[2]` 等文献引用标记转换为 Word 自动脚注
- 脚注格式：每页重新编号，阿拉伯数字上标，宋体小五号
- 脚注中的文献格式与参考文献一致

### 步骤 7：图表处理

- **三线表**：按章节编号（如表1），表标题在表上方，仿宋/宋体五号居中。三线表格式：顶线、栏目线为粗线（1.5磅），底线为粗线（1.5磅），无竖线，无横线（除顶线、栏目线、底线外）
- **图**：按章节编号（如图1），图标题在图下方，仿宋/宋体五号居中
- 图片文件按文章顺序存放：`input/{数字编号}/photo/`，编号从 1 开始递增
- 添加交叉引用

### 步骤 8：参考文献

- 标题"参考文献"作为一级标题，页位于奇数页
- 条目宋体小四号，顶格排列
- 序号使用方括号 `[1]`，序号后空1格
- 超过1行悬挂缩进2字符
- 中文文献分隔符用全角圆点，外文文献题目用斜体

### 步骤 9：附录与致谢

- **附录**：单独成页（奇数页），标题"附 录"宋体三号加粗居中。附录编号带"附录"字样
- **致谢**：单独成页（奇数页），标题"致 谢"宋体三号加粗居中。若论文未提供致谢内容，自行撰写约70字
- **成绩评定表**：空白页

### 步骤 10：奇数页控制与封底

- 封面、学术承诺页、中文摘要、目录、正文、参考文献、附录、致谢首页必须位于奇数页
- 如不在奇数页，插入空白页填充
- 封底：空白页（学校统一模板）

### 步骤 11：保存与输出

- 从论文 Markdown 内容中提取论文主标题作为文件名
- 输出到 `output/` 目录
- 文件名格式：`{论文标题}.docx`
- 如果 `output/` 目录不存在，先创建

### 步骤 12：添加批注（如果 minimax-docx 支持审阅功能）

- 添加批注1：”请确认目录是否可自动更新（右键目录 → 更新域）”
- 添加批注2：”请确认三线表格式是否规范（顶线、栏目线为粗线，底线为粗线，无竖线）”
- 添加批注3：”请确认奇偶页页眉页脚是否规范（奇数页右对齐，偶数页左对齐）”
- 添加批注4：”请确认脚注是否规范（自动脚注，数字上标，字体）”

### 步骤 13：用户确认论文主体

- 生成完成后，提示用户：**”请检查除封面封底外的论文结构是否正确”**
- 如果用户说”没问题”或”可以”，进入步骤 14

### 步骤 14：收集封面信息并填写

- 询问用户以下信息（一次性）：
  1. 专业代码（如”120103”）
  2. 中文题目
  3. 英文题目
  4. 姓名
  5. 学号
  6. 班级
  7. 专业
  8. 学院
  9. 指导教师（含职称，如”李旭鹏 讲师”）
  10. 完成时间（格式如”2026年5月5日”）

- **格式规则**：
  - 中文内容：宋体四号加粗、居中
  - 数字：Times New Roman四号加粗、居中
  - 英文题目：Times New Roman四号斜体（不加粗）、左对齐
  - 其余全部居中

- **专业代码填写**：模板封面第一行有”学校代码    10125                        专业代码               “，共4个 run。第4个 run 是带下划线的空白占位符。在 `MergeTemplate` 中调用 `FillMajorCode(outBody, majorCode)` 方法：
  - 遍历封面第一个段落的 runs
  - 找到包含”专业代码”文本的 run
  - 取其下一个 run（应有 Underline 属性）
  - 将其 Text 替换为居中填充的专业代码（总宽度15字符，与学校代码对齐）：`new string(' ', padLeft) + majorCode + new string(' ', padRight)`

- 在 `MergeTemplate` 方法之后调用 `FillCoverTable` 方法，将用户信息写入封面表格
- 封面表格位于 `outBody.Elements<Table>().FirstOrDefault()`，共9行，每行第3列（index 2）为填写目标
- 中文/数字混合内容需按字符类型拆分 run：中文字符用 SimSun 字体，ASCII/数字用 Times New Roman 字体

### 步骤 15：合并封面封底

- 参照 `封面封底合并流程.md` 的详细说明执行
- 核心操作：打开模板 `template\附件4：本科学年论文封面、说明、承诺使用页、封底示例 .docx`，将其封面3页（封面+说明+学术承诺/使用授权）插入论文最前面，封底1页插入论文最后面
- 模板中的分节符替换为分页符，避免打乱论文节结构
- 模板中的图片复制到输出文档并更新关系 ID
- 在 `settings.xml` 中添加 `<w:compat><w:ulTrailSpace/></w:compat>` 以显示尾部空格下划线
- 合并完成后，提示用户：**”请在 Word 中检查学术承诺页和使用授权页的签名下划线长度是否合适，如需调整请在空格处按空格键增加长度”**
