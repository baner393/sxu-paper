# 封面封底合并流程

## 前置条件

- 已通过 C# 代码生成论文主体内容（中文摘要→致谢）
- 论文主体已通过用户确认（结构、格式正确）
- 模板文件存在：`template\附件4：本科学年论文封面、说明、承诺使用页、封底示例 .docx`

## 模板结构

模板共 4 页：
| 页码 | 内容 |
|------|------|
| 第1页 | 封面（学校代码、校徽图片、"本科学年论文"、信息表格） |
| 第2页 | 说明（打印要求、装订顺序等） |
| 第3页 | 学术承诺 + 使用授权说明（含签名下划线） |
| 第4页 | 封底（校徽图片、学校名称） |

模板内部通过 2 个分节符（sectPr in pPr）分隔：
- 第1个分节符：说明页末尾 → 分隔"封面+说明"与"学术承诺"
- 第2个分节符：学术承诺页末尾 → 分隔"学术承诺"与"封底"
- 最终 sectPr：封底末尾（body 级别）

## 合并策略

1. 生成论文主体文档（7节结构，含页眉页脚、页码等）
2. 打开模板，读取 body 的全部子元素
3. 识别模板中的分节符位置（2 个 in-pPr sectPr）
4. 将模板内容分为：
   - **封面区域**（第1个分节符之前的全部内容）
   - **封底区域**（第2个分节符之后、最终 sectPr 之前的内容）
5. 用 `CloneNode(true)` 深克隆每个元素，过程中：
   - 移除原模板的 sectPr（分节符），替换为分页符（`Break{Type=Page}`）
   - 复制模板中的图片到输出文档，更新关系 ID
   - 设置 `xml:space="preserve"` 保留空格下划线
6. 封面区域插入到论文主体最前面
7. 封底区域插入到论文主体最后面（最终 sectPr 之前）

## 关键代码位置

文件：`build/ThesisBuilder/Program.cs`

核心方法：
- `H.MergeTemplate()` — 主合并逻辑
- `H.CopyImages()` — 复制图片部件
- `H.CloneWithoutSectPr()` — 克隆元素并处理 sectPr→分页符
- `H.UpdateBlipIds()` — 更新图片关系 ID
- `H.FixSignatureUnderlines()` — 加长签名下划线

## 关键设置

### 尾部空格下划线

必须在 `settings.xml` 中添加兼容性设置：
```xml
<w:settings>
  <w:compat><w:ulTrailSpace/></w:compat>
</w:settings>
```

C# 代码（直接写 XML）：
```csharp
var settingsPart = mainPart.AddNewPart<DocumentSettingsPart>();
using (var sw = new StreamWriter(settingsPart.GetStream(FileMode.Create)))
{
    sw.Write(@"<?xml version=""1.0"" encoding=""UTF-8"" standalone=""yes""?>
<w:settings xmlns:w=""http://schemas.openxmlformats.org/wordprocessingml/2006/main"">
  <w:compat><w:ulTrailSpace/></w:compat>
</w:settings>");
}
```

### xml:space 保留

模板中签名处的下划线由带 `w:u w:val="single"` 的空格 run 构成。`CloneNode` 可能丢失 `xml:space="preserve"` 属性，需要显式补回：
```csharp
t.Space = SpaceProcessingModeValues.Preserve;
t.SetAttribute(new OpenXmlAttribute("xml", "space",
    "http://www.w3.org/XML/1998/namespace", "preserve"));
```

### 中英文混合处理

文本按字符类型拆分为独立 run：
- 中文字符 → `EastAsia="SimSun"` + `Ascii="Times New Roman"`
- ASCII/数字/空格 → `EastAsia/Ascii="Times New Roman"`
- 例如"文化产业管理2班"拆为"文化产业管理"(SimSun) + "2"(TNR) + "班"(SimSun)
- 例如"李旭鹏 讲师"拆为"李旭鹏"(SimSun) + " "(TNR) + "讲师"(SimSun)

## 注意事项

1. **图片复制**：模板中的校徽和学校名称是嵌入图片，必须复制 ImagePart 并更新关系 ID
2. **分节符替换**：原模板用分节符分页，合并后必须替换为分页符，否则会打乱论文的节结构
3. **签名下划线**：`CloneNode` + `OuterXml` 是保留格式的最可靠方式。下划线长度由用户手动在 Word 中按空格调整
4. **字体缺失**：模板可能使用特殊字体（如"方正硬笔行书简体"），若系统未安装该字体，Word 会使用替代字体，可能导致签名处空格宽度变化
5. **文件占用**：生成前必须关闭 Word 中的输出文件和模板文件
6. **SectionType 顺序**：论文主体 sectPr 中 SectionType 必须在 pgSz 之前，headerRef/footerRef 必须在最前面
7. **封面表格填写**：必须在合并后、保存前调用，因为表格是从模板克隆来的，合并前表格还不存在于输出文档中
8. **英文题目不加粗**：英文题目只有斜体（`Italic`），不加 `Bold`，且左对齐而非居中

- [ ] 封面、说明、学术承诺各页正确分页
- [ ] 签名处下划线可见（若不可见，检查 ulTrailSpace 设置）
- [ ] 封底校徽和学校名称正常显示
- [ ] 论文主体页眉页脚不受封面封底影响
- [ ] 页码从中文摘要页开始为Ⅰ
