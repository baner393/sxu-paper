# 锚点格式规范 (Anchor Specification)

## 核心原则

Block ID 是整个系统的基石。回填完全依赖 Block ID 定位原 DOCX 段落。

## Block ID 规则（永久稳定）

```
<!-- block:{type}{id} -->
```

- **禁止删除** — AI 编辑 Markdown 时不得删除任何锚点注释
- **禁止修改** — 不得修改 ID 编号或类型前缀
- **禁止重复** — 每个 Block ID 全局唯一
- **必须唯一** — 同一文档内不允许两个相同 ID
- **必须长期稳定** — 同一篇论文的同一段落，每次提取 ID 不变

## Block 类型

| 类型 | 前缀 | 示例 | 说明 |
|------|------|------|------|
| 段落 | `p` | `<!-- block:p182 -->` | 正文段落 |
| 标题 | `h` | `<!-- block:h5 -->` | 标题（含层级信息） |
| 图片 | `img` | `<!-- block:img_12 -->` | 图片引用 |
| 表格 | `tbl` | `<!-- block:tbl_3 -->` | 表格 |
| 公式 | `eq` | `<!-- block:eq_8 -->` | 公式 |
| 摘要 | `abs` | `<!-- block:abs_zh -->` | 中文摘要 |
| 关键词 | `kw` | `<!-- block:kw_zh -->` | 关键词 |
| 参考文献 | `ref` | `<!-- block:ref_0 -->` | 参考文献条目 |

## Markdown 示例

```markdown
<!-- block:h5 -->
# 1 绪论

<!-- block:p182 -->
短视频平台的快速发展深刻改变了当代大学生的学习行为和信息获取方式。

<!-- block:img_12 -->
![图3-1](assets/images/img_12.png)

图3-1 系统结构图

<!-- block:tbl_3 -->
| 变量 | 系数 | 显著性 |
|------|------|--------|
| 学习投入 | -0.32 | p<0.01 |

<!-- block:eq_8 -->

$$
E = mc^2
$$

<!-- block:ref_0 -->
[1] 王兴超, 田芳芳. 大学生短视频成瘾与学业成绩的关系[J]. 华南师范大学学报, 2025(1):12-20.
```

## AI 编辑约束

### 允许的操作
- 修改正文段落内容（`block:p*`）
- 修改表格单元格内容（`block:tbl*`）
- 修改公式内容（`block:eq*`）

### 禁止的操作
- 删除任何 `<!-- block:... -->` 锚点
- 修改 Block ID 编号
- 修改 `block:img*` 的图片路径
- 修改标题层级结构（`block:h*` 的 `#` 数量）
- 修改资源路径（`assets/images/`）
- 移动锚点到其他段落

## meta.json 格式

```json
{
  "source_docx": "paper.docx",
  "title": "论文标题",
  "block_count": 382,
  "extracted_at": "2026-05-21T12:00:00"
}
```

回填时用于校验 Markdown 与 DOCX 的匹配性。
